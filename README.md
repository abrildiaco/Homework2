# Homework2

En este repositorio se encuentran las soluciones de los ejercicios del Homework2 de la materia Paradigmas de la Programacion.

## Archivos

Cada carpeta contiene tres tipos de archivos:

--> Un archivo .h que contiene las declaraciones de las clases

--> Un archivo de .cpp para la definición de cada clase

--> Un archivo main.cpp el cual contiene el código principal que deberá ser ejecutado


## Compilacion

A continuación, se dejan las intrucciones para compilar cada ejercicio

### -Ej1:

g++ -std=c++20 main1.cpp reloj.cpp -o main1

./main1

### -Ej2:

g++ -std=c++20 main2.cpp curso.cpp -o main1

./main2

### -Ej3

g++ -std=c++20 main3.cpp real.cpp entero.cpp complejo.cpp -o main3

./main3

### -Ej4

g++ -std=c++20 main4.cpp cuenta_banco.cpp cuenta_corriente.cpp caja_ahorro.cpp -o main4

./main4
